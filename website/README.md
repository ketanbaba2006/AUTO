# AUTO Official Website & Download Portal

This directory contains the source code for the official public website and release download portal for **AUTO — Your Personal AI Desktop Companion**.

## Tech Stack
- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Icons**: Lucide React
- **Design System**: Official AUTO Dark Theme (`#0A0E1A`, `#00F0FF`, `#8B5CF6`)

## Available Scripts

### Development Server
```bash
npm install
npm run dev
```
Starts local server at `http://localhost:3000`.

### Production Build
```bash
npm run build
```
Compiles static site into `website/dist/` (build time < 1 second).

### Local Preview
```bash
npm run preview
```
Previews the production build locally.
